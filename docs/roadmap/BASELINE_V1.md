## 5. Test status from a clean clone (2026-11-02)

- What was run: a fresh clone of branch `growmoe-lab` at the tagged commit, using the environment already on this machine (a fresh install from `requirements-lock.txt` was **not** tested), `python -m pytest -q` with 4 threads on logical processors 6-11 at below-normal priority.
- Result: 1915 passed, 27 failed, 1 skipped, 2 xfailed, in 662 s.
- All 27 failures have one cause: `yggdrasil_engine.dll` is not in git (`rust_yggdrasil/target/` is ignored) and the tests say to run `cargo build --release` in `rust_yggdrasil`. They are in `tests/test_dynamic_moe.py`, `tests/test_geometry_consistency.py`, `tests/test_geometry_layers.py`, `tests/test_gpu_kernel_bridge.py` and `tests/yggformer/test_yf_kernels.py`.
- After `cargo build --release --offline` in the clone (7 seconds, local cargo cache, no network) the same five files give 34 passed; in the main tree they also give 34 passed. The whole suite was not re-run end to end after the build.
- Bar (b) of M0 ("the full suite passes from a clean clone") is therefore met only with the documented build step. To reproduce: clone; install the packages of `requirements-lock.txt` (untested); run `cargo build --release` in `rust_yggdrasil`; run `python -m pytest -q`.
- Not in this commit: the FS-MoE code and tests and the knowledge-status lab (832 files held by the commit gate, D-72). The counts above therefore exclude their tests.
