## Core Capabilities & Formulations

### 1. Abductive Sense-Making & Contradiction Lie-Detector
The engine evaluates whether any incoming observation **makes sense** relative to its accumulated lifelong experience:
1. **Top-Down Surprise Metric**: Evaluates manifold deviation from prior expectations:
   $$S = d_{\mathcal{S}}(\mathbf{u}_{\text{obs}}, \mathbf{u}_{\text{prior}}) + |\ln(r_{\text{obs}}) - \ln(r_{\text{prior}})|$$
2. **Pearl Level 3 Causal Inversion**:
   $$\mathbf{z}_{\text{abduced}} = \mathcal{W}_{\text{bwd}}(\mathbf{z}_{\text{in}}, \mathbf{z}_{\text{prior}})$$
3. **ACT Deliberation (System 1 vs. System 2)**:
   - Coherent inputs: Pass immediately through System 1 ($1$ step, mean surprise $\approx 0.04$).
   - Anomalous / Contradictory inputs: Trigger Adaptive Computation Time (ACT) deep deliberation ($6$ steps, mean surprise $\approx 1.67$, a **$38.77\times$ anomaly elevation**).

   $$C = \frac{1}{1 + S + \|\mathcal{W}_{\text{bwd}}(\mathbf{z}_{\text{deliberated}}, \mathbf{z}_{\text{in}}) - \mathbf{z}_{\text{abduced}}\|_2^2}$$

### 2. Cross-Domain Riemannian Analogical Reasoning
Analogical transfer solves $A : B :: C : D$ (e.g. *Sun is to Planet as Nucleus is to Electron*) by mapping concepts to points on $\mathcal{S}^{D-1}$ and parallel transporting the transformation tangent vector along the geodesic connecting $A$ and $C$:
1. Compute tangent transformation vector $\mathbf{v} \in T_{\mathbf{a}}\mathcal{S}^{D-1}$:
   $$\mathbf{v} = \text{Log}_{\mathbf{a}}(\mathbf{b})$$
2. Parallel transport $\mathbf{v}$ along the minimal geodesic from $\mathbf{a}$ to $\mathbf{c}$ to obtain $\mathbf{w} \in T_{\mathbf{c}}\mathcal{S}^{D-1}$:
   $$\mathbf{w} = \mathcal{P}_{\mathbf{a} \to \mathbf{c}}(\mathbf{v}) = \mathbf{v} - \frac{\langle \text{Log}_{\mathbf{a}}(\mathbf{c}), \mathbf{v} \rangle}{d_{\mathcal{S}}(\mathbf{a}, \mathbf{c})^2} \left(\text{Log}_{\mathbf{a}}(\mathbf{c}) + \text{Log}_{\mathbf{c}}(\mathbf{a})\right)$$
3. Map to the target manifold position $\mathbf{d}$:
